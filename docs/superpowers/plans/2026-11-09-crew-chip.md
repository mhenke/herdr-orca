# Crew chip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port Orca's collapsed orchestration pill — status marks, stacked agent marks and a count — into `mods/orca-pane`, and the crew list it opens.

**Architecture:** One mod gains two modes. The header instance draws a chip when the pane's terminal has a crew; clicking it opens the same mod as a pointer popup, whose `render` branches on `props().overlay` and draws the list. Crew data is a pure function of `terminals()` (`parent`, `status`, `state`), so it lives in `crew.js` and is unit-tested with `node --test`; the drawing lives in `main.js` with marks copied from `orca-spaces`.

**Tech Stack:** Plain ES modules for Herdr App's GPUI mod API (`gpui-kit`), `node:test` for the pure module, `python3 scripts/verify.py` + `herdr-app check` + `herdr-app shot` for the rest.

**Spec:** `docs/superpowers/specs/2026-11-09-crew-chip-design.md`

## Global Constraints

- AGENTS.md rules bind: port behaviour from the named Orca file (rule 1), every mod draws alone with its own asset copies (rule 9), only real symbols (rule 12), no `setTimeout`/`setInterval` — use `cx.timer.every` (rule 13).
- Dropped on purpose, named in code comments: Orca's `PanelRight` glyph and divider, `shadow-floating`, `Talking with`, the card's collapse button and per-row menus, row previews.
- Never read `t.app` from `terminals()`; the agent's app key is `t.report?.app`.
- Crew = children with `state === "live"` and a `status`, plus the parent when it has a `status` (Herdr's own rule, `herdr-app/defaults/mods/agents/main.js:176`).
- Status words are Herdr's four: `blocked | working | done | idle`. Group order is exactly that order.
- `node --check` and `python3 scripts/verify.py` must pass before every commit.

```js
// mods/orca-pane/crew.js
// The agents a pane's terminal reports for, from Herdr's one crew relation: a terminal can name
// a parent. Herdr's own agents mod walks the same link with the same live-state filter
// (`herdr-app/defaults/mods/agents/main.js:176`), so a mod does see `parent`.
//
// Status words are Herdr's four (`Model::rollup`, herdr-app/src/model.rs:554), in urgency order.
export const STATUS_ORDER = ["blocked", "working", "done", "idle"];

export function crewOf(all, address) {
  if (!address) return { managing: [], managedBy: null };
  const managing = all.filter((t) => t.parent === address && t.state === "live" && t.status);
  const parentAddr = all.find((t) => t.address === address)?.parent ?? null;
  const managedBy = parentAddr ? anyAgent(all, parentAddr) : null;
  return { managing, managedBy };
}

function anyAgent(all, address) {
  return all.find((t) => t.address === address && t.status) ?? null;
}

export function crewMembers(crew) {
  const seen = new Set();
  const members = [];
  for (const t of [...crew.managing, ...(crew.managedBy ? [crew.managedBy] : [])]) {
    if (seen.has(t.address)) continue;
    seen.add(t.address);
    members.push(t);
  }
  return members;
}

export function crewGroups(crew) {
  const members = crewMembers(crew);
  return STATUS_ORDER
    .map((status) => ({ status, members: members.filter((t) => t.status === status) }))
    .filter((group) => group.members.length > 0);
}

export function crewSignature(crew) {
  return crewMembers(crew).map((t) => `${t.address}:${t.status}`).join(",");
}
```

- [ ] **Step 2: Write the marks module**

```js
// mods/orca-pane/status.js
// Ported from mods/orca-spaces/status.js (which ports Orca's StatusIndicator and AgentStateDot);
// a mod draws alone, so this is a copy with this folder's asset paths (AGENTS.md rule 9).
import { div, svg, image } from "gpui-kit";

// Orca's tokens (`main.css:254-258`): --agent-question orange-600, --agent-working yellow-500,
// done emerald-500, idle neutral-500 at 40%.
export const STATUS_COLORS = {
  blocked: "#ea580c",
  working: "#eab308",
  done: "#10b981",
  idle: "#73737366",
};

const box = (size) => div().size(size).flex_none().flex().items_center().justify_center();
const dot = (size, inner, color) => box(size).child(div().size(inner).rounded_full().flex_none().bg(color));

// `StatusIndicator.tsx`: a 12px box holding an 8px mark. `blocked` is Orca's permission glyph;
// `working` is the 8px ring (`AgentWorkingSpinner.tsx:38-41`), never a filled dot; `done` and
// `idle` are 8px dots, idle at 40% alpha.
export function statusMark(status, size = 12, colors = STATUS_COLORS) {
  const c = colors ?? STATUS_COLORS;
  if (status === "blocked") {
    return box(size).child(svg("mods/orca-pane/message-circle-question.svg").size(size).flex_none().text_color(c.blocked));
  }
  if (status === "working") {
    return box(size).child(svg("mods/orca-pane/agent-working-spinner.svg").size(8).flex_none().text_color(c.working).spin(1000));
  }
  return dot(size, 8, status === "done" ? c.done : c.idle);
}

// Orca's catalog marks (`agent-catalog.tsx:50-122`); same table as `orca-spaces`, `orca-tabs` and
// `orca-float`. `svg()` is a one-color mask, so marks that bring their own fills are images.
const OWN_FILLS = new Set(["omp", "droid", "kilo"]);
const AGENT_MARKS = {
  codex: "mono",
  omp: "mods/orca-pane/agent-icons/omp.svg",
  gemini: "mods/orca-pane/agent-icons/gemini.png",
  cursor: "mods/orca-pane/agent-icons/cursor.png",
  grok: "mods/orca-pane/agent-icons/grok.png",
  qoder: "mods/orca-pane/agent-icons/qoder.png",
  hermes: "mods/orca-pane/agent-icons/hermes.png",
  "dsh-tui": "mods/orca-pane/agent-icons/dsh.png",
  droid: "mods/orca-pane/agent-icons/droid.svg",
  kilo: "mods/orca-pane/agent-icons/kilo.svg",
  aider: "mods/orca-pane/agent-icons/aider.svg",
};

// `terminals()` names the agent's app in `report.app`, not `app`.
export function agentMark(term, size = 13, theme) {
  const over = AGENT_MARKS[term?.report?.app];
  const p = term?.program;
  if (over === "mono") return p?.icon ? svg(p.icon).size(size).flex_none().text_color(theme.muted) : null;
  if (over) return OWN_FILLS.has(term.report?.app) || !over.endsWith(".svg")
    ? image(over).w(size).h(size).flex_none()
    : svg(over).size(size).flex_none().text_color(theme.muted);
  if (!p?.icon) return null;
  return p.tint ? svg(p.icon).size(size).flex_none().text_color(theme.muted) : image(p.icon).w(size).h(size).flex_none();
}
```

Add these methods before `render`:

```js
  // Orca's collapsed pill (`OrchestrationCrewPanel.tsx:344-380`): `Workflow` + the managing count,
  // then a status mark and a stack of agent marks per status group. Two pieces are dropped:
  // `PanelRight` and its divider (they read "open the right panel"; this opens a popup) and
  // `shadow-floating` (no shadow token in this theme).
  crewChip(pane, t) {
    const groups = crewGroups(this.crew);
    const label = groups.map((g) => `${g.members.length} ${GROUP_WORD[g.status]}`).join(", ");
    return h_flex()
      .id(`pane-crew-${pane}`)
      .h(22)
      .px(5)
      .gap(4)
      .items_center()
      .flex_none()
      .rounded(4)

      .border_color("#ffffff14")
      .bg("#ffffff0a")
      .text_color("#a1a1aa")
      .hover((s) => s.bg("#ffffff14").text_color("#ffffff"))
      .cursor_pointer()
      .tooltip(`Orchestration: ${label}`)
      .role("button")
      .accessibility_label(`Show orchestration: ${label}`)
      .on_click((_e, cx) => {
        cx.stop_propagation();
        openOverlay({ mod: "orca-pane", kind: "popup", width: 300, props: { pane } });
      })
      .child(svg("mods/orca-pane/workflow.svg").size(12).flex_none())
      .child(div().text_size(11).child(String(this.crew.managing.length)))
      .children(groups.map((g) => h_flex().gap(2).items_center().flex_none()
        .child(statusMark(g.status, 12, t))
        .child(agentStack(g.members, t))));
  }

  // `CrewAgentStack` (`CrewAgentIcons.tsx:186-215`): up to 3 overlapping 16px circles, a 13px
  // mark in each, `+N` for the rest of that group.
  agentStack(members, t) {
    const shown = members.slice(0, 3);
    return h_flex().items_center().flex_none()
      .children(shown.map((m, i) => {
        const mark = agentMark(m, 13, t);
        return div().size(16).rounded_full().flex().items_center().justify_center()
          .bg(t.surface).when(i > 0, (el) => el.ml(-6))
          .when(Boolean(mark), (el) => el.child(mark));
      }))
      .when(members.length > shown.length, (el) =>
        el.child(div().ml(2).text_size(10).text_color(t.muted).child(`+${members.length - shown.length}`)));
  }
```

```js
  // Orca's expanded card (`OrchestrationCrewPanel.tsx:284-330`): 36px title, one section per
  // relation with an uppercase count, then lean rows. Row previews, the collapse button and the
  // per-row menus are dropped: Herdr has no task or question text, closing the popup is the
  // collapse, and focus is the only row action.
  crewCard() {
    const t = theme();
    const address = props()?.pane
      ? panes().find((p) => p.pane === props().pane)?.terminal ?? null
      : panes().find((p) => p.focused)?.terminal ?? null;
    const crew = crewOf(terminals(), address);
    const sections = [
      ["Managing", crew.managing],
      ["Managed by", crew.managedBy ? [crew.managedBy] : []],
    ].filter(([, rows]) => rows.length > 0);

    return v_flex()
      .id("orca-crew-card")
      .w_full()
      .bg(t.surface)
      .text_color(t.foreground)
      .child(h_flex().h(36).flex_none().px(12).items_center().border_b(1).border_color(t.border)
        .child(div().text_size(12).font_medium().child("Orchestration")))
      .children(sections.map(([title, rows]) =>
        v_flex().pt(12).pb(6)
          .child(h_flex().px(12).pb(6).gap(6).items_center()
            .child(div().text_size(10).font_semibold().text_color(t.muted).child(title.toUpperCase()))
            .child(div().text_size(10).font_semibold().text_color(t.muted).child(String(rows.length))))
          .children(rows.map((m) => this.crewRow(m, t)))));
  }

  crewRow(m, t) {
    const mark = agentMark(m, 13, t);
    return h_flex()
      .id(`crew-row-${m.address}`)
      .h(24)
      .w_full()
      .pl(12)
      .pr(6)
      .gap(4)
      .items_center()
      .cursor_pointer()
      .hover((s) => s.bg("#4040402e"))
      .role("button")
      .accessibility_label(`${titleOf(m)} — ${m.status}`)
      .on_click((_e, cx) => {
        cx.stop_propagation();
        run("agent.focus", { terminal: m.address });
        closeOverlay(props().overlay);
      })
      .child(statusMark(m.status, 12, t))
      .when(Boolean(mark), (el) => el.child(mark))
      .child(div().min_w(0).flex_1().truncate().text_size(12).child(titleOf(m)));
  }
```
