# Architecture Decision Records (ADRs)

This directory documents the core architectural decisions, constraints, and deliberate divergences from upstream Orca and Herdr App.

| ADR | Title | Date | Status | Core Decision / Scope |
|:---|:---|:---:|:---:|:---|
| [0001](0001-reviews-read-from-cache.md) | Read reviews from a cache, write them off the render path | 2026-11-07 | accepted (amended by [0009](0009-invariant-space-folder-and-review-store-ttl.md)) | Separates pure synchronous review reading in render from asynchronous background fetching (`review-store.js`, `pr.cache.v2`). |
| [0002](0002-render-failures-are-visible.md) | A mod's `cx` dies with the call that handed it over | 2026-11-07 | accepted | Enforces GPUI context generation lifecycle. Prohibits stored `cx`, `setTimeout`, and `setInterval`; mandates `cx.spawn` and `cx.timer`. Error overlay banner on render failures. |
| [0003](0003-a-float-cannot-hold-a-toggleable-terminal.md) | A float cannot hold a toggleable terminal, so it floats agents | 2026-11-07 | accepted | Because Herdr commands cannot toggle float trees and mods cannot host PTY terminals, `orca-float` (`ctrl-alt-a`) floats live agent sessions rather than a toggleable terminal workspace. |
| [0004](0004-match-orca-layout-and-render-gaps.md) | Match Orca's layout; where Herdr has no backend, render the gap | 2026-11-07 | accepted | Features lacking a Herdr backend (Tasks, Automations, Mobile, Ports, Checks) are rendered with Orca's unavailable-state geometry and an honest gap explanation rather than being omitted or faked. |
| [0005](0005-live-agent-scoping-vs-transcript-indexing.md) | Scope Agents panel from live host models, not on-disk transcript indexing | 2026-11-07 | amended / partially superseded by [0008](0008-transcript-history-off-the-render-path.md) | Binds live agent views directly to in-memory `agents()`, enforcing Herdr's 4-state status vocabulary (`working`, `blocked`, `done`, `idle`) and 3-way `VaultScopeSwitch`. |
| [0006](0006-tab-surface-and-actions-port.md) | Porting Orca tab capabilities and context actions to Herdr | 2026-11-07 | accepted (amended by [0007](0007-terminal-panel-capabilities-and-actions.md) §7 and [0012](0012-multi-tab-split-groups-vs-pane-hierarchy.md)) | Ports tab dragging/reordering, 10-color swatches, status indicators, and modal close guards. Replaced boundary drop limitation with transparent overlay window. |
| [0007](0007-terminal-panel-capabilities-and-actions.md) | Porting Orca terminal panel capabilities, actions, and menu routing | 2026-11-07 | accepted (amended by [0012](0012-multi-tab-split-groups-vs-pane-hierarchy.md)) | Terminal context menu actions (`orca-menu`), scrollback copy, reset, agent handoffs, and layout routing (`terminal_menu: "orca-menu"`). |
| [0008](0008-transcript-history-off-the-render-path.md) | Add bounded transcript history beside the live agent list | 2026-11-07 | accepted (amends [0005](0005-live-agent-scoping-vs-transcript-indexing.md)) | Decouples past session history from the render path via 60s background timer and `cx.spawn`, reading up to 12 bounded OMP sessions. |
| [0009](0009-invariant-space-folder-and-review-store-ttl.md) | Invariant Space Scope and Decoupled Review Store with TTL Invalidation | 2026-11-07 | accepted | Anchors all views strictly to `space.folder` invariant. Upgrades review cache to `review-store.js` with dual TTLs (60s/15m) and explicit invalidation upon PR creation in `orca-changes`. |
| [0010](0010-per-file-provenance-and-mixed-licensing.md) | Per-File Provenance and Mixed Licensing | 2026-11-07 | accepted | Establishes package-wide Apache-2.0 licensing, per-file MIT attribution headers for close Orca ports, and cataloguing of ports and standalone assets in `NOTICE`. |
| [0011](0011-jump-palette-vs-picker-and-command-palette.md) | Jump Palette vs Picker and Command Palette | 2026-11-07 | proposed (unimplemented specification) | Architectural specification for dedicated `mods/orca-palette` modal dialog unifying search across tabs, worktrees, actions, and creation. Currently unbuilt (`orca-nav` uses `picker`). |
| [0012](0012-multi-tab-split-groups-vs-pane-hierarchy.md) | Multi-tab split groups vs single-active-tab pane hierarchy | 2026-11-09 | accepted (amends [0006](0006-tab-surface-and-actions-port.md) and [0007](0007-terminal-panel-capabilities-and-actions.md)) | Documents why Herdr's single-active-tab model cannot represent center-merge tab groups. Establishes 20% outer edge split fallback, persistent 32px attached header, and unsplit-to-tab mechanics. |
| [0013](0013-clipboard-writes-reach-both-gpui-and-the-host.md) | Clipboard writes reach both GPUI and the host display server | 2026-11-09 | accepted (replaces 0013's native-GPUI-only premise) | `copyText` writes GPUI's in-app clipboard first, then the host display server through one probe shell (`wl-copy` / `xclip` / `pbcopy` / `powershell.exe`) with text on argv and both streams closed. The 15 s hang was the forked selection daemon inheriting `exec`'s pipes, not the tool; no temp files remain. `terminal.ctrl-v` maps to `terminal.paste` to match Orca. |
| [0014](0014-mod-side-provider-quota-probing.md) | Mod-Side Provider Quota Probing | 2026-11-09 | accepted | Herdr models no LLM accounts or rate limits, so `orca-status` probes local provider credentials/CLIs in mod code and renders Orca's tightest-window usage chips, rather than waiting for a native quota subsystem. |
